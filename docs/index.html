Features

Everything you need. Nothing you don't.

Sane defaults and guardrails that hold up in production, with clear seams to extend as your app grows.

Typed IPC end-to-end

Every channel declared once in shared/protocol.ts as a Zod schema. Compile-time types and runtime validation — both from the same source of truth.

Sandboxed renderer

sandbox: true, contextIsolation: true, nodeIntegration: false. The renderer's only capability is the minimal window.api exposed via contextBridge.

Multi-window, zero boilerplate

Single bundle, URL hash routing. One createWindow({ entry, parent }) factory for every window — modal child support included.

Cross-window reactive state

State lives in the main process. Typed broadcast() events keep every open window in sync — no client-state library can do this across processes.

Structured logging + redaction

Per-launch timestamped files, bounded rotation, all-process coverage. Sensitive keys are scrubbed from IPC payloads before anything touches disk.

Built to extend

Add a channel: declare a schema, declare a response type, implement the handler. Typed, validated, and logged — automatically. The compiler guides you.

Auto-Update (VSCode-style)

Check → Download → Restart, all user-initiated. electron-updater with a GitHub provider, typed update:* events, and a tag-triggered release workflow. No-op in dev.

Stack

Modern. Stable. Opinionated.

Every choice is here for a reason — and swappable when your requirements differ.

Quick Start

Up in under a minute.

Clone, install, and run. No configuration required to get started.

bash 
# Clone the repository
git clone https://github.com/sandeep-menon/windows-electron-starter-kit.git
cd windows-electron-starter-kit

# Install dependencies
npm install

# Start in development mode (renderer HMR)
npm run dev

# Build a Windows installer
npm run build:win

Dev (renderer HMR)

npm run dev

Dev (full rebuild)

npm run dev:watch

Type check

npm run typecheck

Package for Windows

npm run build:win

Ready to build?

Clone the repo, run npm install, and start building your app on a foundation that holds up in production.

Auto-Update

Ship updates like VSCode.

Check → Download → Restart. Three steps, all user-initiated. A tag push is all it takes to ship a new version.

How it works

  1. User clicks Check for Updates
  2. Update found → Download button appears
  3. Progress bar streams download
  4. Download done → Restart to Update

autoDownload: false and autoInstallOnAppQuit: false — the user is always in control.

Shipping a release

terminal 
# bump version in package.json, then:
git tag v1.2.0
git push && git push --tags
# release workflow builds + publishes automatically

Self-hosted runner

Need code signing or a private fork? Change runs-on: windows-latest to runs-on: [self-hosted, Windows] in release.yml and register your dev machine as a runner in repo settings. Set GH_TOKEN and GH_TOKEN_RO as machine-level env vars.
